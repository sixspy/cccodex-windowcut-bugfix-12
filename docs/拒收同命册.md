> 择定后**当日禁止改口**；偏离本册的拒收写入一律拒写，并在 `audit_trail`
> 记 `reject_fate_drift`（同命偏了）。

## 口径（机器可读，ingest_svc 启动/拒收前校验）

口径: 甲
日期: 2026-11-21
状态: 锁定

## 择定路径：甲——事件与凭证同库同事务

窗外拒收时，`events`（处置=拒收）与 `reject_slips`（拒收凭证）在**同一个
数据库事务**内提交：

1. 占入账锁 `ingest:{window_name}`（先落锁行并提交，使并发者可见）；
2. 同事务依次写 `events` 拒收行、`reject_slips` 凭证行（字段同源：
   window_name / biz_key / event_ts / amount / created_at 一致）、
   `audit_trail` 的 `ingest_reject`；
3. 任一写失败 → 整事务回滚，两侧零改，返回 500；
4. 全部成功 → 一次 `commit`，随后按既有契约返回 409 拒收提示。

**禁止**改用乙路径（先写 reject_draft 再原子出示）；禁止甲乙混用；
禁止只改拒收提示而不保证同命运。

## 五处同态

| 处 | 口径 |
|----|------|
| 事件 events | 拒收事件与 reject_slips 一一对应、字段同源 |
| 凭证 reject_slips | 每张凭证对应且仅对应一条拒收事件，无孤儿凭证 |
| 窗口 windows | 拒收不改窗口 status/generation |
| 审计 audit_trail | 每笔拒收一条 ingest_reject；争用记 ingest_lock_contention；偏离记 reject_fate_drift |
| 争用 contention_log | 两人同时拒收同窗键，后到只记争用（409），业务零写 |

## 争用口径

`ingest:{window_name}` 为入账锁。并发撞锁（唯一约束冲突或 `database is locked`）
由 ingest_svc 统一识别：后到者写 contention_log + 审计后返回 409 争用，
不得排队后双双写入，不得抛 500。
